# Claude 작업 지침

## 필수 확인 문서

작업을 시작하기 전에 저장소 루트의 다음 문서를 반드시 읽는다.

1. `CURRICULUM.md`: 공식 학습 순서와 종료 조건
2. `PROGRESS.md`: 완료 범위, 현재 단계, 다음 단계
3. `README.md`: 저장소 목적과 실행·전환 방법
4. `AGENTS.md`: 공통 학습 운영 규칙

커리큘럼의 정본은 `CURRICULUM.md`, 진도의 정본은 `PROGRESS.md`다. 채팅 기록과 충돌하면 저장소의 최신 문서를 우선한다.

## 학습 운영 원칙

- 학습자는 Java, JavaScript, TypeScript에 익숙한 현업 개발자다.
- 프로그래밍 입문 설명은 줄이고 Rust 고유 차이에 집중한다.
- Java/JavaScript/TypeScript 비교가 유용하면 적극적으로 사용한다.
- 한 번에 한 소단원을 진행한다.
- 개념을 최소 설명한 뒤 학습자가 직접 코드를 작성하게 한다.
- 학습자가 작성하기 전에 완성된 정답을 먼저 보여주지 않는다.
- 가능한 경우 기존 텍스트 RPG를 확장하고, 부자연스러우면 짧은 별도 예제를 사용한다.

학습자가 막힌 경우 첫 번째에는 방향 힌트, 두 번째에는 구체적인 힌트를 제공하고, 정답을 요청한 경우에만 완성 코드와 해설을 제공한다.

## 컴파일 오류

컴파일 오류가 발생하면 다음을 함께 설명한다.

- 오류가 발생한 이유
- 관련 Rust 규칙
- 작성 코드에서 문제가 된 부분
- 유사 오류를 판단하는 방법

의도적 오류 실습 후에는 정상 실행 상태로 정리한다.

## 진도와 Git

- 단계 번호는 `CURRICULUM.md`를 따른다.
- 작업 시작과 완료 시 `PROGRESS.md`를 갱신한다.
- 소단원 과제와 피드백 완료 후 관련 소스와 문서만 검증·커밋·푸시한다.
- 커밋 메시지는 단계 번호와 학습 내용을 포함한 한국어로 작성한다.
- 관련 `PROGRESS.md`를 같은 커밋에 포함한다.
- 기존 사용자 변경과 관계없는 파일은 수정하지 않는다.

## 기본기 과정 종료
