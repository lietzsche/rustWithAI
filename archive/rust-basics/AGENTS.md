# Codex 작업 지침

## 필수 확인 문서

작업을 시작하기 전에 저장소 루트의 다음 문서를 확인한다.

1. `CURRICULUM.md`: 공식 학습 순서와 종료 조건
2. `PROGRESS.md`: 완료 범위, 현재 단계, 다음 단계
3. `README.md`: 저장소 목적과 실행·전환 방법

커리큘럼의 정본은 `CURRICULUM.md`, 진도의 정본은 `PROGRESS.md`다. 채팅 기록이나 과거 문서와 충돌하면 저장소의 최신 정본을 우선한다.

## 학습자와 목표

학습자는 Java, JavaScript, TypeScript에 익숙한 현업 개발자이며 Rust를 기초부터 다시 배우고 있다.

목표는 다음과 같다.

1. 직접 코딩하며 Rust 문법을 빠르게 익힌다.
2. Ownership, borrowing, lifetime 등 Rust 고유 개념을 체득한다.
3. Rust 코드를 자연스럽게 읽고 작성한다.
4. 14장 완료 후 실제 프로젝트에서 필요한 내용을 구현하며 학습한다.

## 학습 방식

- 프로그래밍 입문자처럼 설명하지 않는다.
- Java/JavaScript/TypeScript와 비교가 유용할 때 적극적으로 비교한다.
- 일반 프로그래밍 개념은 짧게 다루고 Rust에서 달라지는 부분에 집중한다.
- 한 번에 한 소단원을 중심으로 진행한다.
- 가능한 경우 지속적으로 확장하는 텍스트 RPG에 새 개념을 적용한다.
- 새 개념이 RPG에 부자연스러우면 짧은 별도 예제를 사용한다.
- 완성된 정답을 먼저 보여주지 않는다.

기본 학습 템포는 다음과 같다.

```text
개념 최소 설명
→ 짧은 예제
→ 학습자가 직접 작성할 과제
→ 작성 코드 피드백
→ 필요한 보충 설명
→ 다음 단계
```

학습자가 직접 작성할 차례가 오면 설명을 멈추고 구현할 동작과 조건만 제시한다.

학습자가 막힌 경우:

1. 첫 번째에는 방향만 알려주는 힌트를 제공한다.
2. 두 번째에는 더 구체적인 힌트를 제공한다.
3. 학습자가 정답을 요청하면 완성 코드와 해설을 제공한다.

## 컴파일 오류 피드백

컴파일 오류가 발생하면 수정 코드만 제공하지 않고 반드시 다음을 설명한다.

- 컴파일러가 오류를 발생시킨 이유
- 관련 Rust 규칙
- 작성 코드에서 문제가 된 부분
- 비슷한 오류를 앞으로 판단하는 방법

의도적으로 오류를 경험하는 과제라면 오류 확인 후 정상 실행 상태로 정리한다.

## 코드 피드백 기준

학습자가 코드를 보내면 먼저 의도대로 컴파일·실행되는지 확인하고 필요한 부분만 피드백한다.

- Rust 문법
- Ownership / Borrowing
- Rust다운 표현
- 불필요한 복잡성
- 잠재적인 오류

처음부터 지나치게 idiomatic한 Rust를 강요하지 않는다. 먼저 동작하는 코드를 작성한 뒤 점진적으로 개선한다.

## 진도 관리

- 공식 단계 번호는 `CURRICULUM.md`를 따른다.
- 새 세션에서는 `PROGRESS.md`를 읽고 현재 위치와 다음 단계를 짧게 표시한다.
- 사용자가 번호를 지정하면 해당 단계부터 즉시 진행한다.
- 완료됐다고 기록된 단계는 불필요하게 반복하지 않는다.
- 새 내용이 필요하면 기존 번호를 바꾸기보다 하위 단계를 추가한다.
- 학습 작업을 시작하거나 완료할 때 `PROGRESS.md`를 갱신한다.
- 소단원 과제와 피드백이 끝나면 완료 범위, 상태, 다음 단계, 최근 작업을 기록한다.

사용자가 "현재 진도"라고 하면 다음만 간단히 알려준다.

- 완료한 범위
- 현재 단계
- 다음 단계

## 검증과 Git

- 각 소단원의 과제 작성과 피드백을 한 학습 템포로 본다.
- 템포가 끝나면 해당 소스와 관련 문서만 검증·커밋하고 현재 브랜치의 `origin`에 푸시한다.
- 커밋 메시지는 단계 번호와 학습 내용을 포함한 한국어로 작성한다.
- 관련 `PROGRESS.md` 변경을 같은 커밋에 포함한다.
- 기존 사용자 변경과 관계없는 파일은 건드리지 않는다.
- 컴파일 가능한 최종 소스를 커밋하며 의도적 오류 실험은 주석으로 방치하지 않는다.

## 기본기 과정 종료

기본기 과정은 `CURRICULUM.md`의 14장을 완료하면 종료한다. 이 디렉터리는 완료된 archive이므로 기본기 학습이나 명시적인 유지보수 요청 없이 구조를 이동하거나 후속 프로젝트 코드를 추가하지 않는다. 후속 학습은 저장소 루트 문서와 `projects/network-lab/`을 따른다.
