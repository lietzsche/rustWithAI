# Network Lab Claude 작업 지침

작업 전에 이 디렉터리의 `README.md`, `CURRICULUM.md`, `PROGRESS.md`, `AGENTS.md`와 저장소 루트 지침을 확인한다.

Network Lab은 문제를 먼저 경험하고 기술의 필요성을 발견하는 프로젝트다. 표준 라이브러리와 blocking I/O에서 시작하며, async/Tokio와 외부 crate는 커리큘럼의 해당 단계 전에는 도입하지 않는다. 모든 구현 과제 전에는 처음 사용하는 Rust 문법과 표준 라이브러리 API의 기본 형태를 과제의 완성 답안과 분리된 작은 예제로 먼저 보여준다. 핵심 구현은 학습자가 직접 작성하도록 하고 힌트를 단계적으로 제공한다.
